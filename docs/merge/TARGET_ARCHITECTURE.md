## 2. 核心用户动线与产品形态

### 2.1 首页：“校园此刻”多频道生态混排
未来的首页不再是一个单纯的孤立贴文列表，而是校园实时活力的聚合体：
- **实时卡片混合流**：
  - **同频搭子卡片**：`[羽毛球] 今晚 7:00 桂航室内球馆差 1 人 · 已报 3/4 · 5分钟前发布`
  - **友桥跨文化卡片**：`[语言交换] David (来自法国) 寻找中文语伴 · 母语法语/流利英语`
  - **二手集市精选**：`[出二手] AirPods Pro 2 ￥699 · 95新支持航天路自提`
  - **校园热门活动**：`[学术/文化] 英语角 English Corner 今晚 19:30 图书馆一楼`
  - **校园圈与树洞**：`[日常] 北苑食堂二楼今天新出脆皮鸡拌饭，值得冲吗？`
- **校区快速切换器**：顶部常驻当前校区标签，无缝在校区与全校大区之间过滤信息。

### 2.2 发现页：全域业务频道枢纽
发现页定位为小程序的“功能罗盘”与次级频道导航中心，采用轻量现代的卡片栅格布局：
1. **同频找搭子 (Tongpin)**：
   - 快速筛选：`约吃饭`、`去运动`、`一起学`、`周末游`、`打游戏`
   - 快速发起组局按钮
2. **友桥跨文化交流 (UniBridge)**：
   - 语言伙伴匹配（中英双语标签）
   - 跨文化工作坊与 English Corner
3. **校园二手集市 (Campus Market)**：
   - 闲置流转、图书教材、数码配件、宿舍神器
4. **校园活动大厅 (Events)**：
   - 讲座、社团汇演、竞赛招募、官方通知日程
5. **校园互助与失物招领**：
   - 寻物启事、跑腿带书、课业交流

## 3. 分包架构落地设计 (Subpackages Plan)

为了防止小程序主包超过 2MB 限制，并为 Tongpin 和 UniBridge 预留足够的空间，制定以下包结构：

```
主包 (Main Package):
  pages/index/        # 首页 (校园此刻)
  pages/discover/     # 发现页 (全频道枢纽)
  pages/post/         # 快速发布选择器 (发布树洞 / 二手 / 搭子 / 活动)
  pages/message/      # 消息聚合列表
  pages/mine/         # 个人中心
  pages/login/        # 登录入驻页
  custom-tab-bar/     # 原生性能自定义底栏
  shared/ & utils/    # 共享核心库、i18n、网络封装

分包矩阵 (Subpackages):
  packageMarket/      # 二手集市专区 (market, market-detail, market-post)
  packageEvents/      # 校园活动专区 (activity, event-detail, admin-activity-zone)
  packageBuddy/       # 同频搭子专区 (buddy-square, buddy-detail, buddy-create, buddy-review)
  packageBridge/      # 友桥专区 (bridge-home, partner-detail, language-onboarding)
  packageCampus/      # 校园深度功能 (treehole-detail, post-editor, follow, share)
  packageSettings/    # 设置与合规 (edit-profile, blacklist, privacy, contact, verification)
```

## 4. 后台管理与全域安全风控体系 (Unified Admin & Safety)

1. **统一举报受理平台**：
   - 一套举报 API 接收贴文、集市宝贝、搭子招募、私信骚扰、语言搭子违规等各类举报。
   - 管理后台统一列表按举报严重程度和可信度评分排序展示证据链。
2. **自动化与人工双重拦截**：
   - **前置**：微信云开发 `security.msgSecCheck` 与 `security.imgSecCheck` 毫秒级机审。
   - **中置**：双向拉黑（Block）在数据层实现静默屏蔽，聊天不可达，列表不可见。
   - **后置**：管理端一键封禁、禁言、下架、信誉分扣减。
3. **数据大屏与留存埋点**：
   - 统计每日新增用户、留存率、搭子成局率、语言搭子匹配成功率、集市成交量。
