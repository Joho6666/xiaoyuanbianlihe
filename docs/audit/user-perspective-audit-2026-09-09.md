# 校园便利盒：用户视角安全与可用性审计

审计日期：2026-09-09

## 结论

本次审计围绕未登录用户、普通用户、内容作者、关注/拉黑用户、私信用户和管理员等角色，检查了前端调用链、CloudBase 云函数、托管后台、配置脚本及文档。已在本分支落地一组可回归验证的修复，重点覆盖越权读取、私有媒体临时链接、公开用户信息、跨 fork 配置和客户端直连数据库等风险。

## 已处理事项

| 领域 | 处理结果 |
| --- | --- |
| 管理后台 | 缺少管理密钥或云函数失败时 fail closed，不再回退到浏览器端数据库读写 |
| 文件访问 | 临时文件 URL 改由云函数统一签发，并按用户可访问资源做 allow-list 过滤 |
| 用户隐私 | 公开用户资料使用字段白名单；关注、粉丝、搜索、个人主页使用 `userRef`，不要求暴露 openid |
| 用户流程 | 分享、个人中心商品、关注/拉黑、个人资料等路径统一经过服务端动作 |
| 项目配置 | 移除维护者环境 ID 的硬编码；部署和 CLI 脚本从 `CLOUD_ENV_ID` 或本地配置读取 |
| 工程质量 | 增加 GitHub Actions 质量检查、JavaScript/JSON 语法检查和安全回归测试 |

## 虚拟测试研究

测试矩阵覆盖 10 类用户流程、10 种输入形状和 10 个数据规模，共 1000 个确定性场景。重点验证：

- 云文件列表去重、格式过滤和 50 项上限；
- 私有文件不应通过临时链接接口泄露；
- 图片、视频、缩略图、头像、封面、音频等媒体字段都能纳入资源收集；
- 用户公开字段不会带出状态、登录时间等内部字段；
- 数字用户 ID 与历史文档 ID 均可解析为内部用户引用。
