## 一、微信开发者工具验收步骤

### 1. 启动与二维码落地体验 (QR Code Landing)
- [ ] **场景 1：无场景值冷启动**
  - 清理本地缓存（Storage -> Clear All），重新编译运行。
  - 验证自动提示选择学校/校区，或默认进入桂林航天工业学院。
  - 检查首页顶部校园生活动态、轮播、热门搭子专区加载顺畅。
- [ ] **场景 2：二维码模拟扫码进入**
  - 在开发者工具顶部「编译模式」中添加自定义编译条件：
    - 启动页面：`pages/index/index`
    - 启动参数（Query）：`schoolId=guet&campusId=guet-huajiang&source=qrcode_poster`
  - 点击编译启动，验证：
    - 无需手动在搜索框检索学校，顶部校区已自动切换为「桂林电子科技大学花江校区」。
    - 首页展示的内容已自动切换到该校区。

### 2. Tongpin 同频搭子闭环 (30 秒极速发布与审批)
- [ ] **步骤 1：三步极速组局 (`packageBuddy/pages/buddy-create/`)**
  - 从发现页或底部「+」进入找搭子发布页。
  - **Step 1 (想做什么)**：点选「🏸 运动」，点击智能标题建议「今晚体育馆羽毛球缺1人双打」，点击「下一步」。
  - **Step 2 (何时何地)**：点选快捷时间「今晚」，地点点选「体育馆」，点击「下一步」。
  - **Step 3 (差几个人)**：点选「4人经典」，检查实时卡片预览呈现「羽毛球 · 今晚 19:30 · 体育馆 · 还差3人」。
  - 点击「🚀 30秒极速发起组局」，应在 1 秒内创建完成并自动跳转搭子详情页。
- [ ] **步骤 2：搭子广场与紧迫度卡片 (`packageBuddy/pages/buddy-square/`)**
  - 进入搭子广场，检查刚发布的组局高亮显示红底标签「今天」或「马上开始」。
  - 检查卡片显示「1/4人 差3人」，突出事件与地点，不强调颜值照片。
- [ ] **步骤 3：申请入局与发起人审批 (`packageBuddy/pages/buddy-detail/`)**
  - 切换测试账号或模拟申请者点击「申请加入组局」，输入留言「自带球拍」并提交。
  - 页面状态变为「申请待确认」，同时出现红色的「撤销申请」按钮。
  - 测试点击「撤销申请」，弹出二次确认后成功撤销。
  - 再次提交申请，发起人进入详情页底部「入局申请待确认」卡片，点击「通过」。
  - 验证：入局人数变为 2/4，申请人界面变为「您已成功入局」，并提供「💬 私信发起人」按钮，点击直接进入聊天。
  - 满员测试：当通过人数达到上限（如 4/4）时，状态自动变为「FULL / 已满员」，后续申请无法再被通过。

### 3. UniBridge 友桥跨文化与语伴交换
- [ ] **步骤 1：极简双语档案配置 (`packageBridge/pages/language-setup/`)**
  - 首次进入友桥广场，点击「设置我的双语档案」。
  - 页面仅展示 2 个必填项：
    - 「1. 我的母语 / 精通语言」：选择中文 (zh)。
    - 「2. 我想学习 / 交流的语言」：选择英语 (en)。
  - 「更多个性化设置」默认折叠，无需填写直接点击「🌍 开启互补语伴匹配」。
  - 验证：成功保存并立即返回广场，完成 3 秒零阻碍冷启动。
- [ ] **步骤 2：真实语伴广场与绝对无假数据 (`packageBridge/pages/bridge-home/`)**
  - 检查广场列表：仅展示真实设置了语言档案的同学，绝对没有任何「法国/留学生」假数据。
  - 检查互补匹配：若当前用户学英语，以英语为母语的语伴卡片上方高亮金色丝带「互补语伴 · 100% 匹配」。
- [ ] **步骤 3：语伴详情与一键打招呼 (`packageBridge/pages/partner-detail/`)**
  - 点击卡片进入详情，检查母语、学习目标、交流方式、匹配原因。
  - 点击「打招呼 / Connect」，无缝唤起一对一聊天窗口。

### 4. 校园互助生活与失物招领 (`packageMutual/`)
- [ ] 进入校园互助，发布一条跑腿求助「带份食堂外卖，酬劳3元」。
- [ ] 列表按「全部/求助/寻物/招领」标签过滤正确。
- [ ] 详情页点击可标记为「已解决」或联系求助人。

### 5. 一对一安全私信 (`pages/chat/`)
- [ ] 发送文本消息与 Emoji，验证发送成功且消息气泡实时出现。
- [ ] 检查聊天双方拉黑机制：在对方主页点击「拉黑」后，私信窗口顶部提示「对方已被拉黑」并禁止发送。

## 二、手机真机验收要点 (iOS / Android)

- [ ] **安全区域适配 (Safe Area Insets)**
  - iPhone 底部 Home 条区域：检查发布页底部按钮、聊天输入框、广场底部浮动按钮均无遮挡。
  - Android 挖孔屏/水滴屏：顶部状态栏与胶囊按钮无视觉重叠。
- [ ] **分包加载性能与体验**
  - 点击「同频搭子」：快速下载分包 `packageBuddy`，无白屏或卡顿（包体积远小于 2MB）。
  - 点击「友桥」：快速下载分包 `packageBridge`。
  - 点击「二手闲置」：快速下载分包 `packageMarket`。
- [ ] **网络与弱网容错**
  - 开启飞行模式后操作：界面优雅提示「网络异常，请重试」，无闪退或红屏。
  - 恢复网络后下拉刷新，列表重新拉取成功。
- [ ] **微信授权与隐私权限**
  - 初次使用时弹出标准微信隐私指引弹窗，点击「同意」后正常运行。
